# Guide des Contrôles - cub3D

## 🎮 Contrôles de Base
- **W** : Avancer
- **S** : Reculer  
- **A** : Strafing gauche
- **D** : Strafing droite
- **← →** : Rotation lente
- **Q** : Rotation rapide gauche
- **E** (maintenu) : Rotation rapide droite
- **R** : Demi-tour instantané (180°)
- **Souris** : Regarder autour

## 🚪 Interaction avec les Portes
- **E** (simple pression) : Ouvrir/fermer une porte
- Approche-toi d'une porte (symbole 'D' sur la carte)
- Regarde dans sa direction et appuie sur **E**
- L'animation d'ouverture/fermeture est automatique

## 🗺️ Carte Actuelle
- Position de départ : près du **N** sur la carte
- Une porte **D** est placée dans le couloir central
- Différentes textures pour chaque direction de mur

## 🎯 Comment Tester
1. **Lance le jeu** : `./cub3D maps/test_simple.cub`
2. **Déplace-toi** avec WASD
3. **Trouve la porte** dans le couloir central
4. **Appuie sur E** pour l'ouvrir
5. **Traverse** quand elle est ouverte
6. **Utilise R** pour faire demi-tour rapidement

Les textures des murs changent selon leur orientation (Nord/Sud/Est/Ouest) et les portes ont leur propre texture spéciale !
